# Simpel Comment Engine
this project was an implementation of comment engine, this project was made to help me
learn more about git and javascript, the feature that i have made on this project include 
- post creation (creating a post)
- comment managemen
- local storage presistence (using JSON)

to try this project make sure you already have nodejs installed on your device
then clone this repo 
```shell
git clone https://github.com/daberpro/koda-b10-node3.git
```

after close this repo install all dependencies this project
```shell
npm i
```
then to execute just run
```shell
npm run dev
```
